
## Принятые допущения

1. У каждого пользователя одна роль; постановщиков и исполнителей может быть несколько.
2. Любой постановщик управляет всеми объектами и задачами, не только созданными им.
3. Исполнитель не может менять название, описание, объект или назначение задачи.
4. Автор и время создания задачи неизменяемы. Идентификатор автора берётся из сессии.
5. При переназначении статус сохраняется; прошлый исполнитель теряет доступ, новый
   получает задачу вместе с историей. Это решение стоит подтвердить у работодателя.
6. «Удалить» означает архивировать: иначе требование сохранить защищённую историю
   конфликтует с физическим удалением задачи. Объект архивируется вместе с задачами.
   Прямой DELETE и изменение истории через API запрещены. Восстановление из архива
   и отдельный экран архива в набросок не включены.
7. Принятая задача не открывается заново: такого перехода в задании нет.
8. Исполнитель видит свой профиль и имена постановщиков для отображения автора;
   профили остальных исполнителей через Data API ему не выдаются.
9. Настоящие пользователи создаются вручную в Auth; назначения ролей через браузер нет.
